# Calibrating_LLM_Agents_CFCN

Research materials for calibrating LLM agents with formation and navigation prompts and comparing their decisions with human experiments.

- **CFCN_Prompt_Generation/**: Notebooks for generating formation and navigation prompts; `outputs/` stores examples of generated prompts and generation records.
- **Kremer_Debo_Simulation/**: LLM replication of the Kremer–Debo experiment, including prompt configuration, training and weight fitting, validation simulations, statistical analyses, and saved results and visualizations.
- **In_Person_Experiment/**: In-person experiment analysis and corresponding LLM simulations. `Human_Results/` contains human data, regression code, and a results report; `LLM_Simulation/` contains simulation code, input weights, and comparisons with human results.
- **Proposal/**: LaTeX proposal source, bibliography, and figures.
