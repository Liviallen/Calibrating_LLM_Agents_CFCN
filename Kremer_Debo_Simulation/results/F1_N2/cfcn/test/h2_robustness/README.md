# H2 follow-up tests: GPT validation run4

Analyzed Q05_Q00_clean.csv and Q50_Q00_clean.csv, restricted to subject_type == 0. Model identity in manifest: gpt5.4; GPT-4o is a legacy dataset label.

The validation code initializes independent conversation histories for each cohort/subject and uses fixed navigation weights. Cohort_id identifies a four-person sequential market, with dependence among decisions within that market. Inference conditions on the trained weights, formation/navigation specification, and this run; it does not measure variation across training runs. Two simulation batches per treatment partition independent cohorts rather than providing only two shared-history units.

## Mean-bias-reduced probit

P(purchase) = Phi(intercept + beta*wait + gamma*treatment + delta*wait*treatment).
H2 predicts delta > 0 on the latent probit scale. Fit with brglm2 AS_mean and probit link, using all observed waits. Resample entire cohorts within treatment and original simulation batch, preserving all uninformed observations in each selected cohort. Seed 20261024; 1999 resamples per comparison, all converged. Fits use aggregated binomial counts for speed; individual-row fits independently verified to agree within 1e-5.

| Comparison | delta | 95% percentile bootstrap CI | Approx. two-sided centered bootstrap p | Holm p across comparisons |
|---|---:|---|---:|---:|
| Q05 vs Q00 | 0.872220 | [0.545805, 1.450438] | 0.0005 | 0.001 |
| Q50 vs Q00 | 2.080778 | [1.277021, 2.868246] | 0.0005 | 0.001 |

Bootstrap p = (1 + count(abs(delta_boot-delta_hat) >= abs(delta_hat)))/(B+1). This is a centered, non-studentized bootstrap approximation, not an exact or ordinary Wald p-value. Neither bootstrap produced an exceedance; 0.0005 is the finite-resample reporting floor, not precise evidence that the true p equals this value. CI evidence is primary. Bias reduction keeps estimates finite but does not create observations in sparse cells. Fitted probabilities near numerical boundaries remain; the finite interaction and bootstrap distribution were checked.

## Linear probability contrast, waits 1 and 2

OLS purchase ~ intercept + wait2 + treatment + wait2*treatment, restricted to waits 1 and 2. Cohort-clustered covariance with finite-sample correction and t reference distribution (G-1 df). Contrast D = [p_Q(2)-p_Q(1)] - [p_00(2)-p_00(1)].

The OLS interaction agrees with the direct four-cell probability contrast. Wait-1 outcomes are constant, making some nuisance coefficient covariance entries zero to numerical precision; inference reported here concerns only the interaction, which has a finite positive variance.

## Conclusion and scope

Both comparisons statistically support H2 under the bias-reduced probit specification. Both also support a smaller decline from wait 1 to wait 2 under the probability-scale follow-up test. The latter is a narrower estimand, not an identical test of the global probit interaction. Q50's point estimate is larger, but these analyses do not test Q50 versus Q05. Tests are two-sided and remain significant with Holm adjustment across the two comparisons within each method. These analyses were chosen after examining separation and outcomes, so report them as follow-up/robustness analyses. The sparse Q00 longer-wait cells limit the global slope analysis. Wait is generated by prior purchasing; results describe conditional behavioral patterns, not a randomized causal effect of wait.
